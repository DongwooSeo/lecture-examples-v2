## 이 브랜치는?

4계층으로 나뉘었지만 주문은 여전히 **상품·결제·유저 서비스 빈을 직접 호출**합니다.

## 오늘 수업에서 하는 것

- **Step 5** 같은 "주문 생성" 유스케이스를 두 방식으로 구현해 나란히 비교
  - 방식 1 **Facade** — 한 트랜잭션 안에서 흐름을 한 곳에 모으기 (결합을 *정리*)
  - 방식 2 **API 호출(HTTP)** — Port + 어댑터로 계약만 공유하기 (결합을 *끊기*)
- 개념: 컨텍스트 맵, Core / Supporting / Generic 도메인, 유비쿼터스 언어
- 강사 시연: 항공 예약 기획서로 용어 사전 → 바운디드 컨텍스트 → 애그리거트 도출
